간단한 웹 개발

누구나 쉽게 시작하고 자신만의 웹을 개발할 수 있습니다.

주요 기능

  • 빠른 시작

    회원가입 없이 바로 확인합니다.

  • 쉬운 사용

    복잡한 설정 없이 이용합니다.

  • 안전한 관리

    정보를 안전하게 보호합니다.

이용 방법

  1. 회원가입 및 로그인
  2. 원하는 코딩 과목을 선택합니다.
  3. 코딩 과목을 선택하면 해당 교실을 배정합니다.
  4. 수업이 끝나면 신청자들의 문의내용을 ai로 정리하여 담당자에게 전송됩니다.
