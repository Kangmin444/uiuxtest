# Re:hear - UI/UX 수업 신청 및 피드백 요청

## 프로젝트 소개
UI/UX 수업을 신청하고, 수업을 수강한 후 담당 강사에게 피드백을 요청하는 과정을 구현입니다. 실제 수업 예약이나 이메일 발송은 이루어지지 않습니다.

- 대상: UI/UX를 배우려는 초보 학습자
- 목표: 학습 목표와 희망 수업 시간을 설정하고, 수업 후 피드백 요청서를 작성하기
- 주요 흐름: 신청 안내 동의 → 학습 목표 입력 → 희망 수업 시간(30·60·90분) 및 질의응답 설정 → 신청 내용 확인 → 수강 여부 확인 → 피드백 요청서 → 이메일 입력

## 7주차 대비 추가 기능
수업 신청 내용 확인을 완료한 뒤 강사 피드백 요청서 작성 기능을 추가했습니다. 수강 여부를 체크하고 피드백 항목과 요청 내용을 입력하면, 앞서 작성한 학습 목표와 함께 요청서를 확인하고 이메일 입력 단계로 진행할 수 있습니다.

| 사용자 행동 | 조건 및 화면 반응 |
| 피드백 요청서 작성 | 수강 확인·항목 선택·내용 입력을 검사하고, 누락 시 오류 안내 |
| 정상 입력 후 확인 | 학습 목표·선택 항목·요청 내용을 화면에 표시 |
| 수정하기 | 작성한 내용을 유지한 채 입력 화면으로 이동 |
| 작성 취소 | 피드백 요청 상태 초기화 및 재시작 가능 |
| 이메일 입력 | 요청서 확인 및 이메일 형식 검사 후 완료 안내 표시(실제 전송 없음) |

## 구현 내용
- HTML: 기존 단계형 수업 신청 화면에 피드백 요청서 영역 추가
- CSS: 흰색·회색·파란색 중심의 단정한 디자인과 모바일 반응형 배치
- JavaScript: 버튼 이벤트, 입력값 검사, 단계 전환, 결과 표시, 수정·취소·초기화 처리 및 기존 오류 수정
